# 37.58. udt_privileges

The view `udt_privileges` identifies `USAGE` privileges granted on user-defined types to a currently enabled role or by a currently enabled role. There is one row for each combination of type, grantor, and grantee. This view shows only composite types (see under [Section 37.60](36.58.-user_defined_types.md) for why); see [Section 37.59](36.57.-usage_privileges.md) for domain privileges.
