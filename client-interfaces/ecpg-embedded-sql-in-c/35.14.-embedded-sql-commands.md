# 36.14. Embedded SQL Commands

[ALLOCATE DESCRIPTOR](35.14.-embedded-sql-commands/ecpg-sql-allocate-descriptor.md) — allocate an SQL descriptor area

[CONNECT](35.14.-embedded-sql-commands/ecpg-sql-connect.md) — establish a database connection

[DEALLOCATE DESCRIPTOR](35.14.-embedded-sql-commands/ecpg-sql-deallocate-descriptor.md) — deallocate an SQL descriptor area

[DECLARE](35.14.-embedded-sql-commands/ecpg-sql-declare.md) — define a cursor

[DECLARE STATEMENT](35.14.-embedded-sql-commands/ecpg-sql-declare-statement.md) — declare SQL statement identifier

[DESCRIBE](35.14.-embedded-sql-commands/ecpg-sql-describe.md) — obtain information about a prepared statement or result set

[DISCONNECT](35.14.-embedded-sql-commands/ecpg-sql-disconnect.md) — terminate a database connection

[EXECUTE IMMEDIATE](35.14.-embedded-sql-commands/ecpg-sql-execute-immediate.md) — dynamically prepare and execute a statement

[GET DESCRIPTOR](35.14.-embedded-sql-commands/ecpg-sql-get-descriptor.md) — get information from an SQL descriptor area

[OPEN](35.14.-embedded-sql-commands/ecpg-sql-open.md) — open a dynamic cursor

[PREPARE](35.14.-embedded-sql-commands/ecpg-sql-prepare.md) — prepare a statement for execution

[SET AUTOCOMMIT](35.14.-embedded-sql-commands/ecpg-sql-set-autocommit.md) — set the autocommit behavior of the current session

[SET CONNECTION](35.14.-embedded-sql-commands/ecpg-sql-set-connection.md) — select a database connection

[SET DESCRIPTOR](35.14.-embedded-sql-commands/ecpg-sql-set-descriptor.md) — set information in an SQL descriptor area

[TYPE](35.14.-embedded-sql-commands/ecpg-sql-type.md) — define a new data type

[VAR](35.14.-embedded-sql-commands/ecpg-sql-var.md) — define a variable

[WHENEVER](35.14.-embedded-sql-commands/ecpg-sql-whenever.md) — specify the action to be taken when an SQL statement causes a specific class condition to be raised

This section describes all SQL commands that are specific to embedded SQL. Also refer to the SQL commands listed in [SQL Commands](../../reference/sql-commands/README.md), which can also be used in embedded SQL, unless stated otherwise.
