## 35.3. `information_schema_catalog_name` [#](#INFOSCHEMA-INFORMATION-SCHEMA-CATALOG-NAME)

`information_schema_catalog_name` 是一個資料表，其中一律只有一列和一個欄位，
內容是目前資料庫的名稱（在 SQL 術語中稱為目前目錄）。
