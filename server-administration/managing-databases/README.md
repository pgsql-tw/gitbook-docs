每個執行中的 PostgreSQL 伺服器實例都會管理一個或多個資料庫。因此，資料庫是組織 SQL 物件（「資料庫物件」）的最上層階層。本章介紹資料庫的特性，以及如何建立、管理與刪除資料庫。
