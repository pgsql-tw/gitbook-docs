## 第 16 章 從二進位套件安裝

<a id="id-1.6.3.2"></a>

PostgreSQL 為目前多數常見的作業系統提供二進位套件。如果有適用套件，建議該系統的使用者以此方式安裝 PostgreSQL。從原始碼建置（請參閱[第 17 章](../installation/README.md)）僅建議用於開發 PostgreSQL 或擴充套件的人員。

提供二進位套件的平台最新清單，請造訪 PostgreSQL 網站的下載區 <https://www.postgresql.org/download/>，並依照特定平台的指示操作。
