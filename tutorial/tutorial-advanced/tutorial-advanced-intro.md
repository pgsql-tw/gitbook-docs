## 3.1. 簡介 [#](#TUTORIAL-ADVANCED-INTRO)

前一章介紹了使用 SQL 在 PostgreSQL 中儲存及存取資料的基礎。現在我們將討論一些更進階的 SQL 功能，讓管理更簡單，並防止資料遺失或損毀。最後，我們會介紹一些 PostgreSQL 的擴充功能。

本章有時會引用[第 2 章](../tutorial-sql/README.md)的範例並加以修改或改善，因此先讀過該章會有所幫助。本章部分範例也收錄在教學目錄的 `advanced.sql` 中。該檔案另包含一些要載入的範例資料，此處不再重複列出。（檔案的使用方式請參閱[第 2.1 節](../tutorial-sql/tutorial-sql-intro.md)。）
