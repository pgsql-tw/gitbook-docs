# 第一部分：教學

<a id="id-1.4.2"></a>

歡迎閱讀 PostgreSQL 教學。本教學旨在介紹 PostgreSQL、關聯式資料庫的概念，以及 SQL 語言。我們假設你具備使用電腦的一般知識，但不需要特別的 Unix 或程式設計經驗。本教學的目的是讓你實際操作 PostgreSQL 系統的重要功能，並不打算完整涵蓋所介紹的各個主題。

順利完成本教學之後，你會想進一步閱讀[第二部分](../the-sql-language/README.md)，以更深入瞭解 SQL 語言；或閱讀[第四部分](../client-interfaces/README.md)，瞭解如何使用 PostgreSQL 開發應用程式。自行建置與管理 PostgreSQL 安裝環境的人，也應該閱讀[第三部分](../server-administration/README.md)。
