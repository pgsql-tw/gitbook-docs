## 2.2. 概念 [#](#TUTORIAL-CONCEPTS)

<a id="id-1.4.4.3.2.1"></a>
<a id="id-1.4.4.3.2.2"></a>
<a id="id-1.4.4.3.2.3"></a>
<a id="id-1.4.4.3.2.4"></a>
<a id="id-1.4.4.3.2.5"></a>
PostgreSQL 是*關聯式資料庫管理系統*（RDBMS）。這表示它是管理儲存於*關聯*中的資料之系統。關聯本質上是*資料表*的數學術語。如今以資料表儲存資料的概念非常普遍，似乎理所當然，但組織資料庫還有其他方式。Unix 類作業系統中的檔案與目錄便構成階層式資料庫的例子；較新的發展則是物件導向資料庫。

<a id="id-1.4.4.3.3.1"></a>
<a id="id-1.4.4.3.3.2"></a>
每個資料表都是具名的*資料列*集合。指定資料表的每筆資料列都有同一組具名的*欄位*，且每個欄位都有特定資料型別。雖然欄位在每筆資料列中有固定順序，請記住 SQL 不以任何方式保證資料表中資料列的順序（雖然可明確排序以供顯示）。

<a id="id-1.4.4.3.4.1"></a>
<a id="id-1.4.4.3.4.2"></a>
資料表會分組成資料庫，而由單一 PostgreSQL 伺服器實體管理的資料庫集合構成資料庫*叢集*。
