# O.5. pg_receivexlog 更名為 pg_receivewal

<a id="id-1.11.16.7.2"></a>

PostgreSQL 9.6 及更早版本提供名為 `pg_receivexlog` 的指令 <a id="id-1.11.16.7.3.2"></a>，用於擷取預先寫入日誌（WAL）檔案。此指令已更名為 `pg_receivewal`。`pg_receivewal` 的文件請參閱 [pg_receivewal](../../reference/client-applications/pg_receivewal.md)，此變更的詳細資訊請參閱 [PostgreSQL 10 發布說明](../release-notes/e.4.-prior-releases.md)。
