# O.5. pg_receivexlog renamed to pg_receivewal

<a id="id-1.11.16.7.2"></a>

PostgreSQL 9.6 and below provided a command named `pg_receivexlog` <a id="id-1.11.16.7.3.2"></a> to fetch write-ahead-log (WAL) files. This command was renamed to `pg_receivewal`, see [pg_receivewal](../../reference/client-applications/pg_receivewal.md) for documentation of `pg_receivewal` and see [the release notes for PostgreSQL 10](../release-notes/e.4.-prior-releases.md) for details on this change.
