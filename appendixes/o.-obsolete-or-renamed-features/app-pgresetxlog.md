# O.4. pg_resetxlog renamed to pg_resetwal

<a id="id-1.11.16.6.2"></a>

PostgreSQL 9.6 and below provided a command named `pg_resetxlog` <a id="id-1.11.16.6.3.2"></a> to reset the write-ahead-log (WAL) files. This command was renamed to `pg_resetwal`, see [pg_resetwal](../../reference/server-applications/pg_resetwal.md) for documentation of `pg_resetwal` and see [the release notes for PostgreSQL 10](../release-notes/e.4.-prior-releases.md) for details on this change.
