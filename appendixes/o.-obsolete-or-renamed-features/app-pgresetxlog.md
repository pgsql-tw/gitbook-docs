# O.4. pg_resetxlog 更名為 pg_resetwal

<a id="id-1.11.16.6.2"></a>

PostgreSQL 9.6 及更早版本提供名為 `pg_resetxlog` 的指令 <a id="id-1.11.16.6.3.2"></a>，用於重設預先寫入日誌（WAL）檔案。此指令已更名為 `pg_resetwal`。`pg_resetwal` 的文件請參閱 [pg_resetwal](../../reference/server-applications/pg_resetwal.md)，此變更的詳細資訊請參閱 [PostgreSQL 10 發布說明](../release-notes/e.4.-prior-releases.md)。
