# O.3. pg_xlogdump 更名為 pg_waldump

<a id="id-1.11.16.5.2"></a>

PostgreSQL 9.6 及更早版本提供名為 `pg_xlogdump` 的指令 <a id="id-1.11.16.5.3.2"></a>，用於讀取預先寫入日誌（WAL）檔案。此指令已更名為 `pg_waldump`。`pg_waldump` 的文件請參閱 [pg_waldump](../../reference/server-applications/pg_waldump.md)，此變更的詳細資訊請參閱 [PostgreSQL 10 發布說明](../release-notes/e.4.-prior-releases.md)。
