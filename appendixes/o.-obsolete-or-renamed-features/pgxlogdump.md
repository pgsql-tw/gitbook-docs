# O.3. pg_xlogdump renamed to pg_waldump

<a id="id-1.11.16.5.2"></a>

PostgreSQL 9.6 and below provided a command named `pg_xlogdump` <a id="id-1.11.16.5.3.2"></a> to read write-ahead-log (WAL) files. This command was renamed to `pg_waldump`, see [pg_waldump](../../reference/server-applications/pg_waldump.md) for documentation of `pg_waldump` and see [the release notes for PostgreSQL 10](../release-notes/e.4.-prior-releases.md) for details on this change.
