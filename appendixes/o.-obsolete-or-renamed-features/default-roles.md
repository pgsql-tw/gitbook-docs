# O.2. Default Roles 更名為 Predefined Roles

<a id="id-1.11.16.4.2"></a>

PostgreSQL 13 及更早版本使用「Default Roles」一詞。不過，這些角色實際上無法變更，並且會在系統初始化時一併安裝，因此較合適的名稱是「Predefined Roles」。關於 Predefined Roles 的現行文件，請參閱[第 22.5 節](../../server-administration/database-roles/default-roles.md)；關於此變更的詳細資訊，請參閱 [PostgreSQL 14 發布說明](../release-notes/e.4.-prior-releases.md)。
