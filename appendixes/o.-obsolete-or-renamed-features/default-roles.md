# O.2. Default Roles Renamed to Predefined Roles

<a id="id-1.11.16.4.2"></a>

PostgreSQL 13 and below used the term “Default Roles”. However, as these roles are not able to actually be changed and are installed as part of the system at initialization time, the more appropriate term to use is “Predefined Roles”. See [Section 22.5](../../server-administration/database-roles/default-roles.md) for current documentation regarding Predefined Roles, and [the release notes for PostgreSQL 14](../release-notes/e.4.-prior-releases.md) for details on this change.
