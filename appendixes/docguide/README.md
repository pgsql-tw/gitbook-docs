PostgreSQL 有四種主要的文件
格式：

* 純文字，用於安裝前的資訊
* HTML，用於線上瀏覽與參考
* PDF，用於列印
* man 手冊頁，用於快速參考。

此外，在 PostgreSQL 原始碼樹中各處，
還可以找到許多純文字的 `README` 檔案，
記載各種實作上的問題。

HTML 文件與 man 手冊頁是
標準發行版的一部分，預設會安裝。PDF
格式的文件則另外提供
下載。
