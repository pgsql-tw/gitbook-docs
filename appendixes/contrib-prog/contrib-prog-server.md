## G.2. 伺服器應用程式 [#](#CONTRIB-PROG-SERVER)

有些應用程式會在 PostgreSQL 伺服器本身執行。目前 `contrib` 目錄未包含這類應用程式。核心 PostgreSQL 發行版中伺服器應用程式的資訊，請另參閱 [PostgreSQL Server Applications](../../reference/reference-server/README.md)。
