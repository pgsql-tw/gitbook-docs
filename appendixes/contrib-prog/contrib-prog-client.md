## G.1. Client Applications [#](#CONTRIB-PROG-CLIENT)

[oid2name](oid2name.md) — resolve OIDs and file nodes in a PostgreSQL data directory

[vacuumlo](vacuumlo.md) — remove orphaned large objects from a PostgreSQL database

This section covers PostgreSQL client
applications in `contrib`. They can be run from anywhere,
independent of where the database server resides. See
also [PostgreSQL Client Applications](../../reference/reference-client/README.md) for information about client
applications that are part of the core PostgreSQL
distribution.
