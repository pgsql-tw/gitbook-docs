由於歷史因素，`inet_ops` 運算子類別並不是 `inet` 與 `cidr` 型別的預設類別。若要使用它，請在 `CREATE INDEX` 中指明該類別名稱，例如

```

CREATE INDEX ON my_table USING GIST (my_inet_column inet_ops);
```
