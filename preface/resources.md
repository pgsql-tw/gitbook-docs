## 4. 更多資訊 [#](#resources) <a href="#resources" id="resources"></a>

除了文件（也就是本書）之外，還有其他關於 PostgreSQL 的資源：

Wiki
:   PostgreSQL [wiki](https://wiki.postgresql.org) 收錄了本專案的 [FAQ](https://wiki.postgresql.org/wiki/Frequently_Asked_Questions)（常見問題）清單、[TODO](https://wiki.postgresql.org/wiki/Todo) 清單，以及許多其他主題的詳細資訊。

網站
:   PostgreSQL [網站](https://www.postgresql.org)提供最新版本的詳細資訊，以及其他能讓你在工作或休閒時更有效率地使用 PostgreSQL 的資訊。

郵件清單
:   郵件清單是讓問題獲得解答、與其他使用者分享經驗，以及聯絡開發人員的好地方。詳細資訊請參閱 PostgreSQL 網站。

你自己！
:   PostgreSQL 是一個開放原始碼專案，因此仰賴使用者社群提供持續的支援。當你開始使用 PostgreSQL 時，你會透過文件或郵件清單依靠他人的協助。請考慮將你的知識回饋出來：閱讀郵件清單並回答問題。如果你學到了文件中沒有的東西，請把它寫下來並貢獻出來。如果你為程式碼新增了功能，也請貢獻出來。
