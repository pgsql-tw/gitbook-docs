# PostgreSQL 伺服器應用程式

---

<a id="id-1.9.5.2"></a>

本部分包含 PostgreSQL 伺服器應用程式與支援工具程式的參考資訊。這些命令只有在資料庫伺服器所在的主機上執行才有用處。其他工具程式列於 [PostgreSQL 用戶端應用程式](../reference-client/README.md)。

**目錄**

[initdb](app-initdb.md) — 建立新的 PostgreSQL 資料庫叢集

[pg_archivecleanup](pgarchivecleanup.md) — 清理 PostgreSQL WAL 歸檔檔案

[pg_checksums](app-pgchecksums.md) — 在 PostgreSQL 資料庫叢集中啟用、停用或檢查資料校驗和

[pg_controldata](app-pgcontroldata.md) — 顯示 PostgreSQL 資料庫叢集的控制資訊

[pg_createsubscriber](app-pgcreatesubscriber.md) — 將實體複本轉換為新的邏輯複本

[pg_ctl](app-pg-ctl.md) — 初始化、啟動、停止或控制 PostgreSQL 伺服器

[pg_resetwal](app-pgresetwal.md) — 重設 PostgreSQL 資料庫叢集的預寫式日誌及其他控制資訊

[pg_rewind](app-pgrewind.md) — 將 PostgreSQL 資料目錄與另一個從它分岔出去的資料目錄同步

[pg_test_fsync](pgtestfsync.md) — 判定 PostgreSQL 最快的 `wal_sync_method`

[pg_test_timing](pgtesttiming.md) — 測量計時的額外負擔

[pg_upgrade](pgupgrade.md) — 升級 PostgreSQL 伺服器執行個體

[pg_waldump](pgwaldump.md) — 以人類可讀的形式顯示 PostgreSQL 資料庫叢集的預寫日誌

[pg_walsummary](app-pgwalsummary.md) — 印出 WAL 摘要檔案的內容

[postgres](app-postgres.md) — PostgreSQL 資料庫伺服器
