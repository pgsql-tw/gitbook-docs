## DROP GROUP

DROP GROUP — 移除資料庫角色

## 語法

```

DROP GROUP [ IF EXISTS ] name [, ...]
```

<a id="id-1.9.3.115.5"></a>

## 說明

`DROP GROUP` 現在是 [`DROP ROLE`](sql-droprole.md) 的別名。

## 相容性

SQL 標準沒有 `DROP GROUP` 陳述式。
