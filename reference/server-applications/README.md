# III. PostgreSQL 伺服器應用程式

本部分包含 PostgreSQL 伺服器應用程式和支援的實用工具參考訊息。這些指令只能在資料庫伺服器所在的主機上有效運行。[PostgreSQL 用戶端工具](../client-applications/)中列出了其他實用工具。

[initdb](initdb.md) — create a new PostgreSQL database cluster

[pg\_archivecleanup](pg_archivecleanup.md) — clean up PostgreSQL WAL archive files

[pg\_checksums](pg_checksums.md) — enable, disable or check data checksums in a PostgreSQL database cluste

[pg\_controldata](pg_controldata.md) — display control information of a PostgreSQL database cluster

[pg\_ctl](pg_ctl.md) — initialize, start, stop, or control a PostgreSQL server

[pg\_resetwal](pg_resetwal.md) — reset the write-ahead log and other control information of a PostgreSQL database cluster

[pg\_rewind](pg_rewind.md) — synchronize a PostgreSQL data directory with another data directory that was forked from it

[pg\_test\_fsync](pg_test_fsync.md) — determine fastest `wal_sync_method` for PostgreSQL

[pg\_test\_timing](pg_test_timing.md) — measure timing overhead

[pg\_upgrade](pg_upgrade.md) — upgrade a PostgreSQL server instance

[pg\_waldump](pg_waldump.md) — display a human-readable rendering of the write-ahead log of a PostgreSQL database cluster

[postgres](postgres.md) — PostgreSQL database server

[postmaster](postmaster.md) — PostgreSQL database server
