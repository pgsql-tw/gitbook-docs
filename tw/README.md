# 首頁

本使用手冊由台灣 PostgreSQL 使用者社群提供，編譯自 PostgreSQL 官方使用手冊，以推廣 PostgreSQL 於台灣的應用。

目前本站所提供的手冊版本為：

* [18](https://app.gitbook.com/o/-L9QNzUOznP9g0-Jt7pf/s/O0nI78FIIp52bwIiUPaa/)
* [17](https://app.gitbook.com/o/-L9QNzUOznP9g0-Jt7pf/s/izt5GEOI22Cr6Qf79dZA/)
* [16](https://app.gitbook.com/o/-L9QNzUOznP9g0-Jt7pf/s/WiHby7mwMGXvwtBoXMT1/)
* [15](https://app.gitbook.com/o/-L9QNzUOznP9g0-Jt7pf/s/Gsf608HyBgnsiEewlozD/)
* [14](https://app.gitbook.com/o/-L9QNzUOznP9g0-Jt7pf/s/-L9nT-o3VuFYbINNfQTx-2545935929/)



此手冊為自由參與的開源專案，歡迎任何夥伴參與協作！

下載及安裝指引，請到[官方下載頁面](https://www.postgresql.org/download/)，依您的環境選擇操作步驟。

任何問題或建議可以 Email 給我們的文件小組：[docs@postgresql.tw](mailto:docs@postgresql.tw)
