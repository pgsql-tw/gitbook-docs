# 49.5. System Catalogs Related to Logical Decoding

The [`pg_replication_slots`](../../internals/system-views/pg_replication_slots.md) view and the [`pg_stat_replication`](../../server-administration/monitoring-database-activity/the-statistics-collector.md#MONITORING-PG-STAT-REPLICATION-VIEW) view provide information about the current state of replication slots and streaming replication connections respectively. These views apply to both physical and logical replication.
