## 36.8. 程序語言函式 [#](#XFUNC-PL)

除了 SQL 和 C 之外，PostgreSQL 也允許使用其他語言撰寫使用者定義函式。這些語言統稱為*程序語言*（procedural languages，PL）。程序語言並非內建於 PostgreSQL 伺服器，而是透過可載入模組提供。更多資訊請參閱[第 40 章](../xplang/README.md)及後續章節。
